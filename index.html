Ecosistema & Plataforma

Core

SDK

El Software Development Kit de Flutter es el conjunto completo de compiladores, herramientas y librerías provistos por Google. No es un simple framework; incluye el motor de renderizado de alto rendimiento y el compilador que traduce el código Dart directamente a instrucciones binarias nativas de cada procesador.

Arquitectura

Desarrollo Mobile

Disciplina enfocada en la creación de software para smartphones y tablets. Flutter redefine este ecosistema al permitir un enfoque de código único (Single Codebase), donde los desarrolladores escriben una sola aplicación que se ejecuta de forma nativa e idéntica tanto en sistemas Android como en iOS.

CLI Tools

Comandos Eficientes

Instrucciones de consola nativas indispensables para optimizar la productividad y automatizar despliegues directamente desde terminales como GitHub Codespaces:

flutter pub get // Sincroniza e instala las dependencias del pubspec.yaml
flutter doctor // Analiza el sistema local y reporta configuraciones faltantes
flutter build web // Compila una versión óptima para subir a GitHub Pages

El Universo de los Widgets

UI Base

Widgets

En Flutter, todo es un widget. Son las piezas de rompecabezas estructurales e inmutables que componen la interfaz de usuario. Desde un simple bloque de texto o un botón, hasta los márgenes (Padding) y las estructuras de alineación (Center) se declaran y configuran mediante widgets.

Estático

StatelessWidget

Componentes visuales inmutables y sin memoria interna. Un StatelessWidget no cambia su apariencia de forma interna una vez construido; si requiere actualización, depende completamente de que su elemento padre le envíe datos nuevos y lo reconstruya desde el exterior. Ideal para títulos, iconos o tarjetas fijas.

Dinámico

StatefulWidget

Un widget dinámico estructurado en dos partes: la clase de configuración visual e inmutable, y una clase de Estado (State) persistente y mutable. Al invocar el método interno setState(), el widget redibuja automáticamente los elementos en pantalla para reflejar cambios interactivos del usuario en tiempo real.
